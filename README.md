# НИЯЗ — сайт-витрина

Статический сайт на Astro. Рабочий каталог: `/Users/niyazlapkovskii/Developer/nijazby`.

## Локальная работа

```sh
npm install
npm run dev
```

В проекте локальный Node 24; команды npm scripts используют его автоматически. Локальный адрес выводится сервером (сейчас `http://127.0.0.1:4321/`).

```sh
npm run typecheck
npm run build
npm test
npm run check
```

Обычная сборка закрыта от индексации. Для подготовки публичного размещения: `npm run build:production`. На хостинг копируется только содержимое `dist/`, никогда не корень проекта.

## Где обновлять контент

- `src/data/company.ts` — контакты.
- `src/data/catalog.ts` — категории и модели.
- `src/data/gallery.ts` — галерея и отзывы.
- `src/data/media.json` — изображения и источник каждого файла.
- `public/images/`, `public/documents/` — только отобранные публичные файлы.
- `docs/photo-checklist.md` — что снять.
- `docs/deployment.md` — публикация и ограничения.
- `docs/content-gaps.md` — недостающие материалы.
- `docs/redirect-map.csv` — карта старых адресов, ещё не серверные правила.

`legacy/` — закрытый архив источников. Не редактировать, не копировать на хостинг. Новые товары без изображений могут использовать явные фотоплейсхолдеры; неизвестные характеристики не придумывать.
