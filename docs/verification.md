# Проверка первой версии НИЯЗ

## Выполнено

- `npm run typecheck`: 29 файлов, 0 ошибок, 0 предупреждений, 0 подсказок.
- Статическая сборка: 15 HTML-страниц, включая 404; 14 адресов в sitemap.
- 16 тестов: готовые страницы, контакты, тактильный ассортимент, сертификат, переключение индексации и исключение 404.
- Публичная сборка отдельно проверена: `PUBLIC_SITE_LIVE=true`, robots разрешает индексацию. Затем восстановлен закрытый предпросмотр.
- Проверены внутренние ссылки, якоря, CSS-ресурсы, JSON-LD, title, h1, sitemap и отсутствие закрытых файлов в dist.
- Главная, каталог, тактильная страница, вибролитьевая плитка и контакты проверены при фактической ширине 360, 390, 768 и 1440 CSS-пикселей. Горизонтального переполнения страницы нет.
- Дополнительно при 360 px проверены «О нас», услуги, укладка, заборы, металлоконструкции и ограничители парковки.
- Мобильное меню открывается и закрывается Escape. Сертификат открывается в диалоге, закрывается Escape с возвратом фокуса на ссылку. Фильтр «Укладка» оставляет одну соответствующую фотографию.
- Основной контент находится в собранном HTML и не требует выполнения JavaScript; меню реализовано нативным details, ссылки на оригиналы фотографий работают без скрипта.
- В браузере не обнаружено ошибок консоли на финальной главной.
- Исправлены мобильное растягивание каталога, контраст мелких надписей и нестабильность фонового изображения при отрицательном z-index.
- Размер dist около 2,5 МБ, включая документы, всю галерею и шрифты. Это не размер первоначальной загрузки одной страницы.

## Ограничения и следующий этап

- Сайт не опубликован, DNS не изменён, доступы к хостингу не предоставлены.
- Lighthouse и полевые LCP/CLS не измерялись; замер на опубликованном хостинге остаётся этапом запуска. Не заявлять оценку производительности или гарантированные поисковые позиции.
- Фотоплейсхолдеры предусмотрены по разрешению владельца. Конкретный список — photo-checklist.md.
- Карта старых URL содержит 103 записи и 26 предложений 301. Она ещё не применена на сервере.
- Размерные единицы вибролитьевых групп не добавлены без подтверждения; пользователь разрешил недостающие сведения дополнять позже.
