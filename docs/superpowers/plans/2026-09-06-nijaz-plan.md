# НИЯЗ — план реализации витрины

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Создать красивую и понятную мобильную витрину НИЯЗ на nijaz.by с каталогом и обращениями по телефону/email.

**Architecture:** Статические страницы Astro, общие компоненты, каталог в типизированных данных. Обновления выполняет агент, готовая сборка размещается на хостинге владельца.

**Tech Stack:** Astro, TypeScript, CSS; минимальный JavaScript для меню и галереи. Конкретные поддерживаемые версии проверить при реализации и зафиксировать lock-файлом.

**Spec:** docs/superpowers/specs/2026-09-06-nijaz-design.md

## Global Constraints

- Рабочий каталог: /Users/niyazlapkovskii/Developer/nijazby.

- legacy не изменять и не публиковать целиком.
- Этот документ — план, не разрешение менять DNS или публиковать сайт.

## Задание на фотографии

Тактильную плитку повторно снимать не требуется: владелец подтвердил пригодность block-1.

1. Главная: один лучший завершённый объект, 3–5 широких кадров; желательно мощение и забор вместе. Оставить свободное спокойное место под заголовок, снять общий план и отдельный вертикальный вариант.
2. Заборы: по одному общему кадру каждой из четырёх групп и крупному плану фактуры. Итого минимум 8 снимков. Подписать группу.
3. Тротуарная плитка: для каждой отсутствующей в пригодном архиве формы — один образец сверху/под углом на одинаковом нейтральном фоне. Подписать название и фактический размер. Дополнительно 3–4 общих вида уложенной плитки.
4. Металлоконструкции: ворота и калитка целиком, затем деталь исполнения. Остальные типы — по мере добавления ассортимента.
5. Ограничители парковки: общий вид изделия и один кадр в установленном виде для каждого типа.
6. Производство и услуги: 2–3 общих кадра производства, один доставки/разгрузки, 2–3 процесса укладки или монтажа.
7. Контакты: въезд и место с образцами, чтобы посетитель узнал площадку.

Приоритет: кадр главной → пять направлений каталога с учётом готовой тактилки → образцы товаров → производство и услуги. Оригиналы желательно от 2500 px по длинной стороне, без надписей, водяных знаков, фильтров и сжатия мессенджером. Снимать при ровном дневном свете. Не требуется заказывать всю съёмку до первого предпросмотра: недостающие кадры заменяются по реестру.
