## Техническое предложение и SEO

Рекомендация: Astro со статической сборкой, TypeScript для данных, обычный CSS и минимум клиентского JavaScript. Итог — HTML/CSS/изображения, размещаемые на хостинге владельца с поддержкой статики. Админка и сервер приложений не требуются. Альтернативы: ручной HTML усложнит единообразные изменения по страницам; CMS добавит обслуживание, которое сейчас не нужно.

Данные компании и товаров отдельно от шаблонов. В публикацию попадают только выбранные обработанные изображения и документы; legacy, sensitive-originals, SQL и PHP никогда не копируются в public или dist.

SEO: полезные короткие тексты категорий, отдельные адреса содержательных направлений, уникальные title/description, один h1 на странице, хлебные крошки, настоящие ссылки между страницами, canonical nijaz.by, sitemap, robots и 404. Семантика — производство/купить/заказать + реальные категории, Барановичи и Беларусь. Не создавать одинаковые страницы для каждого города. Разметка Organization и BreadcrumbList из видимых подтверждённых данных; не подставлять фиктивные цены, рейтинг или Offer с нулевой ценой.

Старые URL nijaz.by сопоставить по смыслу с новыми страницами. Для релевантных перенесённых материалов подготовить 301; для исключённых без замены — корректный 404/410 после решения на этапе запуска. Не перенаправлять всё на главную. Для тактильная.бел возможен технический 301 на новое направление, если владелец сохранит управление доменом; это не второй сайт. Решение об отключении и изменение DNS выполняются только на этапе публикации.

После получения доступа при запуске: проверить Google Search Console и Яндекс Вебмастер, отправить sitemap. Аналитику и измерение кликов подключать при наличии согласованных счётчиков; клик по телефону не считать состоявшимся звонком.
