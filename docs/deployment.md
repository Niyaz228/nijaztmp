# Публикация nijaz.by

Сайт подготовлен для статики, но ещё не опубликован. Доступ к хостингу и тип веб-сервера пока неизвестны. Изменений DNS и отключения тактильная.бел не выполнялось.

## Перед загрузкой

1. Согласовать внешний вид и допустимые фотоплейсхолдеры.
2. Получить способ доступа к хостингу, корневую папку сайта, тип сервера и настройки HTTPS. Секреты не сохранять в репозитории или документации.
3. Проверить, что доступна раздача `index.html` из каталогов и корректная 404-страница. Сайт не является SPA; не направлять все неизвестные адреса на главную с кодом 200.
4. Собрать публичный вариант: `npm run build:production`.
5. Выполнить `npm test` и `npm run check`; дополнительно убедиться, что robots разрешает индексацию и обычные страницы имеют `index, follow`.
6. Создать резервную копию текущего опубликованного сайта перед заменой.
7. Загрузить только содержимое `dist/`. Папки `legacy`, `src`, `docs`, `node_modules`, `.env` и архивы не загружать.

## На сервере

- HTTPS и единый канонический адрес `https://nijaz.by`.
- Серверные 301 на основе рассмотренной карты `redirect-map.csv`. Строки review автоматически не применять.
- Настроить 404 на `404.html` с реальным кодом 404.
- Долгий cache для хешированных `/_astro/*`; HTML с обновляемым кешем; корректные MIME для CSS/JS/WebP/WOFF2.
- Если пользователь сохранит управление тактильная.бел для перехода, можно настроить HTTP 301 на `/catalog/taktilnaya-plitka/`. Это необязательное предложение, не согласованное действие с доменом.

## После загрузки

Проверить главную, категории, услуги, контакты, изображения, документ, robots, sitemap и несколько старых адресов. При доступе к Google Search Console и Яндекс Вебмастер добавить sitemap и проверить индексирование. Измерить скорость на опубликованном хостинге, включая LCP/CLS и мобильные условия. Реальные звонки и письма сайт не отправляет автоматически: ссылки открывают телефон или почтовый клиент пользователя.
